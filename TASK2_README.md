Bank Account & ATM Simulation Engine

Project Description

A Java-based banking application that simulates basic ATM operations using Object-Oriented Programming concepts.

Features

- Check account balance
- Deposit money
- Withdraw money
- Savings account with interest calculation
- Checking account with overdraft limit
- PIN verification
- Transaction history with timestamps
- Custom exception handling

Technologies Used

- Java (JDK 17+)
- Object-Oriented Programming
- ArrayList Collections
- Exception Handling

OOP Concepts

- Encapsulation
- Inheritance
- Abstraction
- Method Overriding
- Polymorphism

Project Files

- Account.java
- SavingsAccount.java
- CheckingAccount.java
- Customer.java
- ATM.java
- InsufficientFundsException.java
- InvalidPINException.java

How to Run

Compile:

javac *.java

Run:

java ATM
